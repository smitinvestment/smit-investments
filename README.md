# Smit Investments — Website

Premium single-page website and financial calculators for **Smit Investments**
(Authorised Mutual Fund & SIF Distributor · ARN-284696 · CFGP).

## Pages
- `index.html` — product portfolio, asset classes, risk–return positioning, approach & contact.
- `calculators.html` — interactive SIP & SWP cash-flow calculators (6 tools).
- `styles.css` — shared theme (indigo/violet on slate).
- `logo.png` — brand logo.

## Hosting
Static site — no build step. Deploy anywhere that serves static files.
On **GitHub Pages**: Settings → Pages → Deploy from branch → `main` / root.
